# PartyAggro335

Небольшой аддон для **оригинального World of Warcraft 3.3.5a**, Interface **30300**.
Показывает сбоку таблицу противников, замеченных в бою вашей группы:

| Моб | Кого бьёт | Агро | HP |
| --- | --- | --- | --- |
| Моб #1 | Хилер | 64% Не на тебе | 82% |
| Моб #2 | Танк | 100% Под угрозой | 71% |
| Заклинатель #3 | ? | ? Нет данных | ? |

Это **пример**, а не снимок работающего клиента.

## Что умеет

- Собирает противников из боевого журнала, ваших целей, фокуса, mouseover,
  целей участников группы/рейда и их питомцев.
- Использует GUID: два моба с одинаковым именем отображаются отдельными строками.
- Выводит цель моба, ваши проценты угрозы и здоровье, когда клиент отдаёт эти данные.
- Поднимает проблемные строки наверх: красные — цель не на вас, жёлтые —
  вы танкуете, но другой участник приблизился по угрозе; зелёные — моб на вас.
  Статусы по последней атаке явно отмечены `~` и могут уже не быть актуальными.
- Показывает рейдовые метки, убирает умерших мобов, очищает список после окончания боя.
- Выделяет вашу текущую цель золотой рамкой, указателем `>` и золотым именем.
  Выделение обновляется сразу при смене цели, в том числе обычным Tab.
  Если цель ниже лимита строк, показывает её в последней видимой строке.
- Поддерживает группу и рейд, русский и английский интерфейс, перенос панели,
  масштаб, число строк и демонстрационный режим.
- Показывает локальные стрелки над стандартными полосками здоровья мобов, бьющих
  другого участника группы. Использует стандартную текстуру стрелки из клиента.
- Работает без библиотек и других аддонов. Таблицу можно использовать вместе с Omen.

## Установка

1. Скачайте `PartyAggro335-0.3.0.zip` из [Releases](https://github.com/Eviltsundera/PartyAggro335/releases).
2. Распакуйте папку **PartyAggro335** в `World of Warcraft/Interface/AddOns`.
3. Проверьте структуру: `Interface/AddOns/PartyAggro335/PartyAggro335.toc`.
4. Полностью перезапустите игру и включите аддон на экране выбора персонажа.

При скачивании исходников через **Code → Download ZIP** скопируйте внутреннюю папку
`PartyAggro335`, а не весь репозиторий.

## Настройка

Вне боя панель по умолчанию скрыта. В бою появляется автоматически.

| Команда | Действие |
| --- | --- |
| `/pa` | Помощь |
| `/pa unlock` | Показать панель и разрешить перенос за заголовок |
| `/pa lock` | Закрепить панель и вернуть автоматическое отображение |
| `/pa show` | Показать панель, разрешить перенос |
| `/pa hide` | Скрыть до следующего `/pa show`, `/pa unlock` или `/pa test` |
| `/pa test` | Включить/выключить пример с четырьмя мобами |
| `/pa rows 16` | Число видимых строк, от 5 до 30 |
| `/pa scale 1.1` | Масштаб, от 0.6 до 1.6 |
| `/pa clear` | Очистить список; обнаруженные снова мобы появятся на следующем обновлении |
| `/pa reset` | Сбросить положение и настройки |
| `/pa arrows on` | Включить стрелки над мобами (включены по умолчанию) |
| `/pa arrows off` | Выключить стрелки |
| `/pa arrows test` | Включить/выключить пример стрелки на выбранном мобе |
| `/pa arrows size 44` | Размер стрелки: 16–64, по умолчанию 36 |
| `/pa debug` | Показать локально количество мобов, доступных данных и распознанных полосок |

Наведение мыши на строку объясняет происхождение данных. Для настройки положения:
`/pa test` → `/pa unlock` → перетащите панель вправо/влево → `/pa lock` → `/pa test`.

### Текущая цель и Tab

Золотая рамка и `>` обозначают выбранного вами моба, цвет агро остаётся прежним.
Мобы с одинаковыми именами различаются по GUID. В `/pa test` рамка на первой строке
показывает пример выделения. Если цель ниже лимита строк, она занимает последнюю
видимую строку; остальные верхние строки сохраняют порядок по опасности.

**Tab использует штатное переключение целей WoW.** Выделение следует за выбранной
целью, но Tab не ограничивается мобами из таблицы и не повторяет порядок её строк.
Аддон не меняет ваши назначения клавиш. Если Tab переназначен, выберите в настройках
клавиш WoW действие «Выбрать ближайшего противника».

Строгое переключение по динамическому списку GUID в бою недоступно в оригинальном
3.3.5a: защищённые действия нельзя перенастраивать из обычного кода во время боя,
а [защищённая среда клиента](https://github.com/wowgaming/3.3.5-interface-files/blob/main/RestrictedEnvironment.lua)
не предоставляет `UnitGUID` для сопоставления мобов со строками. Список также включает
противников из боевого журнала, у которых может не быть доступного unit-токена.
Выбор по имени не решает проблему одинаковых мобов. Поэтому строки остаются
информационными; клик и Tab по порядку таблицы не добавлены.

### Стрелки над мобами

Включите **полоски здоровья врагов клавишей V**. Красная стрелка указывает на моба,
для которого есть актуальная информация о цели/агро не на вас. Жёлтая стрелка —
последняя замеченная ближняя атака на другого игрока; это предположение, действующее
не больше 2.5 секунд. Настройки рейдовых меток аддон не меняет.

Стрелка — локальная текстура над **неймплейтом**, которая следует за видимым мобом.
Это не изменение 3D-модели и не встроенный указатель выбранной цели. Вне экрана или
без неймплейтов стрелка не отображается. Для проверки вне боя: выберите моба,
`/pa arrows test`, затем повторите команду для выхода из теста.

В старом клиенте у неймплейта нет доступного GUID. Аддон связывает его с мобом по
выбранной цели, настоящему mouseover, существующей рейдовой метке либо однозначному
совпадению имени и текущего/максимального здоровья. **Имя само по себе не используется**.
Одинаковые мобы с одинаковым здоровьем могут оставаться неопределёнными: наведите
курсор на нужную полоску или выберите моба. После скрытия/повторного использования
неймплейта его привязка и стрелка очищаются.

Стрелки рассчитаны на стандартную структуру неймплейтов 3.3.5a. Аддоны, заменяющие
её или меняющие прозрачность/цвет стандартных элементов, могут мешать распознаванию.

## Как читать данные

- **100%** — ваши проценты относительно порога захвата цели. У танкующего игрока
  обычно будет 100%; это **не** запас угрозы над вторым игроком.
- **«Под угрозой»** — встроенный статус 2: вы танкуете, но кто-то имеет 100% или
  больше необработанной угрозы относительно вас. Это сигнал клиента, а не прогноз по DPS.
- **`?` / «Нет данных»** — доступных актуальных данных нет. Аддон не подставляет 0%
  и не рассчитывает агро из нанесённого урона.
- Начиная с 0.2.0, при недоступных процентах статус может определяться из стандартного
  индикатора угрозы над распознанным мобом. Процент при этом остаётся `?`.
- **`~На тебе` / `~Не на тебе`** — статус по последней замеченной ближней атаке.
  Процент неизвестен; это наблюдение, а не текущий запрос таблицы угрозы.
- Имя **без `~`** — текущая цель доступного юнита по API клиента.
- **`~Имя`** — предположение по встроенному API угрозы либо последняя замеченная
  цель ближней атаки. Вторая информация живёт не больше 2.5 секунд.
- Если текущая цель моба — другой участник вашей группы, строка может быть красной
  даже при неизвестном проценте агро. Процент останется `?`.

### Ограничения оригинального 3.3.5a

Аддон видит только события, полученные вашим клиентом. Он не может гарантировать
полный список мобов за пределами радиуса боевого журнала. Цели и здоровье доступны
для разрешимых юнитов; попытка запроса угрозы по GUID используется только если
клиент поддерживает её и возвращает данные. Мобы без текущих данных остаются в списке
с неизвестными значениями; устаревшие наблюдения удаляются через 25 секунд.

Босс может временно выбирать другого игрока для заклинания или игнорировать агро.
Столбец «Кого бьёт» и статус угрозы при этом могут различаться.

Строки **информационные**: они не меняют цель и не используют таунт. Аддон не обходит
защищённые действия в бою и не требует модификации клиента.

Автоматические тесты выполняются в Lua 5.1 с имитацией API 3.3.5a, включая пул и
структуру старых неймплейтов, одинаковые имена, очистку стрелок и неизвестные данные.
Стрелки и выделение текущей цели версии **0.3.0** требуют проверки в живой группе/рейде; совместимость
с конкретным сервером и полнота его данных не гарантируются.

## Разработка и тесты

```sh
python -m pip install -r tests/requirements.txt
python tests/run.py
python tools/package.py
```

Тесты проверяют Lua 5.1, формат старого боевого журнала, фильтрацию чужих боёв,
одинаковые имена, смерть и исчезновение мобов, устаревание и недоступность данных,
цветовые статусы, сохранение настроек, неоднозначные неймплейты, существующие метки,
стрелки, выделение по GUID, смену цели, лимит строк и загрузку UI с имитацией WoW API.

Проект использует только API эпохи 3.3.5a: `GetNumPartyMembers`, `GetNumRaidMembers`,
аргументы `COMBAT_LOG_EVENT_UNFILTERED` из события. Здесь нет `C_NamePlate`,
`CombatLogGetCurrentEventInfo` и современных unit-токенов `nameplateN`.
